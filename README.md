# Finars Studio 3.1

Sodobna, prenovljena spletna stran arhitekturnega biroja **FIN ARS d.o.o.** (Zagorje ob Savi, Slovenija).

## Značilnosti

- Dizajn v stilu Apple / vrhunskih arhitekturnih birojev
- Popolnoma odzivna (desktop + mobile)
- Animirano ozadje z arhitekturnimi fotografijami
- Lightbox zoom za vse slike projektov
- Podstrani: Domov, Projekti, O nas, Storitve, Kontakt
- Individualne strani za vsak projekt z originalnimi barvnimi slikami s finars.si
- Čist, minimalističen in profesionalen UI

## Projekti vključeni

- Olimpijski bazen & wellness Libija (2013)
- Prenova OŠ Revirski borci, Trbovlje (2013)
- Stanovanjsko naselje Podčetrtek (2013)
- Urbana dnevna soba na deželi (2011)
- CZS – Center za družbene dejavnosti (2011)
- Stanovanja R (2011)
- Vrtec Kisovec (2010)
- Mercator Škofja Loka (2010)
- SPAR Litija (2007)
- Blok K3 (2007)
- Avtohiša S (2007)

## Tehnologije

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Inter)
- Originalne slike hostane na finars.si

## Kako zagnati

Odprite `index.html` v brskalniku ali namestite lokalni strežnik:

```bash
npx serve .
```
